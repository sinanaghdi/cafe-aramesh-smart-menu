# منوی هوشمند کافه آرامش

منوی دیجیتال فارسی و راست‌چین برای کافه آرامش؛ با هدف تبدیل منوی ثابت به تجربه‌ای پویا، مشتری‌محور و مبتنی بر داده.

## وضعیت فعلی

فاز اول آغاز شده است: پوسته اولیه رابط فارسی، طراحی واکنش‌گرا، محصولات نمونه، فیلتر دسته‌بندی، جست‌وجوی ساده، سبد نمایشی و پیش‌نمایش پنل کارکنان و صاحب کافه در مخزن قرار دارند.

**توجه:** نسخه فعلی نمونه رابط کاربری است. هنوز بک‌اند، پایگاه داده، ورود امن، ثبت سفارش واقعی، تأیید کد، باشگاه مشتریان واقعی و تحلیل فروش متصل به داده وجود ندارد. اعداد یا پنل‌های نمایشی نباید به‌عنوان داده واقعی تلقی شوند.

## مشاهده پروژه

فایل `index.html` را در مرورگر باز کنید یا برای مشاهده آنلاین از قابلیت GitHub Pages استفاده کنید. این نسخه استاتیک است و به‌تنهایی سفارش واقعی یا احراز هویت را اجرا نمی‌کند.

## مراحل توسعه

1. پایه رابط فارسی و طراحی RTL
2. API و پایگاه داده منو و مدیریت محصولات
3. سبد درخواست و تأیید حضوری توسط کارکنان
4. کمبوهای قابل مدیریت و جست‌وجوی زبان طبیعی فارسی
5. حالت مطالعه و باشگاه مشتریان
6. تحلیل سفارش‌های تکمیل‌شده و پیشنهادهای داده‌محور برای صاحب کافه
7. تست امنیت، دسترس‌پذیری و استقرار

جزئیات در `docs/ROADMAP.md` و `docs/PRODUCT-SPEC.md` آمده است.

## اصول محصول

- رابط کاربری فارسی و راست‌چین در همه نقش‌ها.
- سه نقش مجزا: مشتری، کارکنان/گارسون و صاحب کافه.
- سفارش در MVP یک درخواست بدون پرداخت آنلاین است و نیاز به تأیید حضوری دارد.
- پیشنهادها باید از داده واقعی منو استفاده کنند.
- آمار نمایشی هرگز به‌عنوان فروش واقعی معرفی نمی‌شود.
- منو جایگزین CRM، حسابداری یا نرم‌افزار کامل مدیریت کافه نیست.

## فناوری

در فاز اول، رابط اولیه با HTML، CSS و JavaScript ساده ساخته می‌شود تا هویت بصری و جریان‌های اصلی قابل بررسی باشند. انتخاب معماری نهایی بک‌اند و پایگاه داده در فاز بعد، پس از ارزیابی نیازهای استقرار انجام خواهد شد.
